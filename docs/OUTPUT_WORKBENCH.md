# Output Workbench / 取模与输出工作台

The Output Workbench is the single byte-generation path for Pixel Studio canvases, selections, the active Designer frame, and FontPack glyphs. Display colors, zoom, output font, and animation speed never change generated bytes.

## Encoding formulas

| UI name | `bit_axis` | `group_order` | Traversal |
|---|---|---|---|
| 逐行式 / Row sequential | `horizontal` | `row_major` | Pack each row left-to-right, then advance to the next row. |
| 行列式 / Row-block column major | `horizontal` | `column_major` | Visit the first horizontal 8-dot block in every row, then the next block. |
| 逐列式 / Column sequential | `vertical` | `column_major` | Pack each column top-to-bottom, then advance to the next column. |
| 列行式 / Page row major | `vertical` | `row_major` | Visit every column in one 8-row page, then the next page. SSD1306 VLSB uses this traversal. |

`msb_first` writes the first sampled point to bit 7; `lsb_first` writes it to bit 0. `one_is_lit` encodes a lit point as 1; `zero_is_lit` encodes a lit point as 0. A partial byte is padded with logical off-points before polarity is applied. The compatibility labels 顺向/逆向 and 阳码/阴码 are not stored as the data contract.

## Rasterization

Color images support integer luma thresholding and `R >= Rmin && G >= Gmin && B >= Bmin`. Fully transparent pixels are always off. `invert_source` operates on rasterized source pixels and is independent from encoding polarity. Font Lab supports a shared font-set reference box or per-glyph-width horizontal centering; both keep one shared baseline. 1-bit PixelDocument, framebuffer, and stored FontPack glyph sources bypass thresholding.

## Formatting and indexes

Text output supports hexadecimal or decimal values, 1–256 bytes per line, minimal data, compact spacing, and literal segment/comment/data/line wrappers. Only `${symbol}`, `${name}`, `${codepoint}`, `${width}`, `${height}`, `${byte_count}`, and `${offset}` are substituted. Unknown placeholders and fields longer than 1024 characters are rejected; templates are never executed.

Font output de-duplicates an explicit character string while retaining its order. Without a string it sorts by Unicode code point. Index rows contain `codepoint`, `offset`, `byte_length`, `width`, `height`, `bearing_x`, `bearing_y`, and `advance`. A sidecar index is saved as `<stem>_index.h` and both files receive SHA-256 results through Automation API.

## Pixel Studio actions

- **生成字模 / Generate** forces the latest valid configuration to render.
- **复制数组 / Copy array** copies the full generated text.
- **保存字模 / Save bitmap** writes the complete text or binary result even when the 256 KiB preview is truncated.
- **清除输出 / Clear output** clears only the preview and animation. It does not alter pixels, FontPacks, or configuration.

The animation reads `trace_step()` from the production encoder and shows the eight sampled coordinates, bit direction, byte value, and current/total byte.

## Project format

The top-level project remains `schema_version: 1`. The optional portable section is:

```json
{
  "output_workbench": {
    "schema": 1,
    "active_profile": "ssd1306_vlsb_c",
    "profiles": {
      "ssd1306_vlsb_c": {
        "name": "SSD1306 VLSB · C Header",
        "raster": {},
        "encoding": {},
        "text": {}
      }
    }
  }
}
```

Opening an older project supplies the default in memory and does not rewrite the file. The first profile edit atomically adds the section. Profile IDs use lowercase ASCII letters, digits, `_`, or `-` and are limited to 64 characters.

## 10×10 golden fixture (MSB first, one is lit)

- 逐行式: `A0 80 40 40 08 00 01 00 10 00 04 00 82 00 20 00 40 80 08 40`
- 行列式: `A0 40 08 01 10 04 82 20 40 08 80 40 00 00 00 00 00 00 80 40`
- 逐列式: `82 00 40 80 81 00 08 00 20 40 04 00 02 00 10 00 80 80 40 40`
- 列行式: `82 40 81 08 20 04 02 10 80 40 00 80 00 00 40 00 00 00 80 40`

These vectors prove the software formula. A target driver’s known-good array and successful panel output are still required to certify a hardware preset.
