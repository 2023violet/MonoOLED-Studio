# G0 立项与基线冻结 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成 Rust 重写的 G0：写入 ADR-005 和连续本地授权；收尾 TASK-003；从 V1 导出可复现的黄金语料；归档 `rust` 分支；最后交出 G0 证据，由用户确认 Gate。

**Architecture:** 语料导出器是一个只读的 Python 工具，放在 `tools/golden_corpus/` 包中，每个类别一个模块。它调用 V1 的生产函数，生成 canonical JSON 写入 `fixtures/golden/`，并由 `manifest.json` 钉住 V1 源文件 blob 和各类别的 SHA。`--check` 模式会重新生成一份，与已提交的语料逐字节比对，供 V1 修 bug 期间防止漂移。G0 不修改 `src/` 下的任何产品代码。

**Tech Stack:** Python 3.13、标准库、V1 现有依赖（Pillow、PySide6 不需要）、pytest、Git。

**Spec:** [docs/rewrite/2026-10-19-rust-rewrite-design.md](2026-10-19-rust-rewrite-design.md)（第 3 节 G0 行、第 4 节语料、第 7 节工作流）

## Global Constraints

- Python 3.13；导出器只使用标准库和 `requirements.txt` 中已有的依赖，不新增依赖。
- 不访问网络；不读取用户目录、环境变量值或凭据。
- 仓库内所有新路径必须是 ASCII（`tests/test_v120_generic_product_closure.py` 有断言）。
- 不得创建 `docs/superpowers/`、`docs/design/`、`docs/archive/`、`docs/releases/`。
- Canonical JSON：`json.dumps(value, ensure_ascii=False, sort_keys=True, separators=(',', ':'), allow_nan=False)`，UTF-8 编码，结尾一个 `\n`，换行一律用 LF。
- 字节字段统一为 `{"hex": str, "byte_count": int, "sha256": str}`。
- 语料级别只有 `strict` 和 `semantic` 两种；新生成的 TTF 字形和含 TTF 文字的场景元素为 `semantic`，其余均为 `strict`。
- 不得宽泛剔除时间戳、路径或空白。唯一允许的替换是把临时项目根目录的绝对路径替换成字面量 `${PROJECT_ROOT}`。
- `src/` 下的产品代码在 G0 中不做任何修改。
- 不得在单个 pytest 进程中运行整个 `tests/`。全量回归使用 `python tools/RUN_WINDOWS_TEST_GROUPS.py --phase source`。
- 连续本地授权在 Task 1 由用户确认之后才生效。此前每次本地提交都需要用户同意；此后 push、远端 tag、删除分支或 worktree、改写历史仍需用户逐次确认。

    if os.name != 'nt':
        pytest.skip('directory junctions are Windows-only')
    result = subprocess.run(['cmd', '/c', 'mklink', '/J', str(link), str(target)],
                            capture_output=True, text=True, check=False)
    if result.returncode:

def test_custom_output_rejects_junction_into_git_metadata(tmp_path):
    repo = _repo(tmp_path)
    _junction(repo / 'gitj', repo / '.git')
    result = _run(repo, '--output', 'gitj/hooks/post-checkout')
    assert result.returncode != 0
    assert '.git directory' in result.stderr
    assert not (repo / '.git' / 'hooks' / 'post-checkout').exists()

def test_custom_output_rejects_junction_outside_repository(tmp_path):
    repo = _repo(tmp_path)
    outside = tmp_path / 'outside'; outside.mkdir()
    _junction(repo / 'outj', outside)
    result = _run(repo, '--output', 'outj/escaped.md')
    assert result.returncode != 0
    assert 'inside the repository root' in result.stderr
    assert not (outside / 'escaped.md').exists()

def test_custom_output_rejects_git_short_name(tmp_path):
    repo = _repo(tmp_path)

- Manifest 结构：

```json
{"schema_version":1,
 "reference":{"python_version":"3.13.x","pillow_version":"...","source_blobs":{"src/<file>.py":"<git blob sha>"}},
 "categories":{"<name>":{"file":"<name>.json","sha256":"...","case_count":0,"levels":{"strict":0,"semantic":0}}}}
```

`source_blobs` 用 `git hash-object src/<file>.py` 计算。覆盖每个类别模块 import 的 V1 源文件，各模块用模块级常量 `SOURCES: tuple[str, ...]` 声明。不记录 commit SHA，这样同一套 V1 源码在不同提交上生成的语料完全相同。
